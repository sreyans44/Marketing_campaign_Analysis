# Marketing_campaign_Analysis
This project focuses on data preprocessing and exploratory data analysis (EDA) of a marketing campaign dataset. The dataset includes customer demographic data, purchasing behavior, and campaign responses. The goal is to clean the data, handle missing values and outliers, and extract useful patterns using visual and statistical analysis.
---

## Project Setup

This project was created using [Google Colab](https://colab.research.google.com/). If you open the `.ipynb` file in Colab, no local setup is necessary. However, if you want to run it locally, follow the instructions below.

---

## Requirements

To run this project locally, you need:

* Python 3.7+
* Jupyter Notebook or Google Colab
* The following Python libraries:

  * pandas
  * matplotlib
  * seaborn
  * numpy

Install the dependencies using pip:

```bash
pip install pandas matplotlib seaborn numpy
```

---

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/sreyans44/Marketing_campaign_Analysis
   ```

2. Navigate to the project directory:

   ```bash
   cd Marketing_campaign_Analysis
   ```

3. Open the .ipnyb notebook:

   * Either in Jupyter Notebook locally
   * Or upload to [Google Colab](https://colab.research.google.com/)

4. Run the notebook cells in order. The code is organized for data preprocessing and exploratory data analysis (EDA) of a marketing campaign dataset.

---

## Contents

* Handling missing values
* Outlier detection using box plots
* Removing duplicates
* Fixing data types (e.g., date conversion)
* Exploratory Data Analysis (EDA)
